# AntiCopyRight - Система обнаружения плагиата

Полноценная система обнаружения плагиата для академических и профессиональных документов.

## 📋 О проекте

AntiCopyRight - это сложная система обнаружения плагиата, использующая передовые методы анализа текста, машинного обучения и обработки документов для выявления потенциального плагиата в академических работах, исследовательских статьях и других документах.

### Основные возможности:
- **Анализ документов**: Разбор и анализ различных форматов документов (PDF, DOCX, TXT и др.)
- **Обработка текста**: Продвинутая нормализация и лемматизация текста
- **Машинное обучение**: Обнаружение схожести на основе Doc2Vec
- **GUI на Qt 6**: Современный, удобный интерфейс
- **Поддержка нескольких языков**: В основном ориентировано на обработку русского языка

## 🔧 Обзор модулей

### Основная библиотека (`lib/`)

- **Config**: Парсинг и управление конфигурационными файлами
- **DocumentManager**: Чтение и обработка различных форматов документов
- **Network**: Сетевое взаимодействие и аутентификация
- **TextAnalyzer**: Конвейер обработки текста с лемматизацией и ML-моделями
  - **Lemmantizer**: Лемматизация русского текста с помощью MyStem
  - **Model**: Реализация модели Doc2Vec для обнаружения схожести
- **Util**: Вспомогательные функции и утилиты

### Приложение (`src/`)

- **main.cpp**: Точка входа в приложение с инициализацией Qt 6
- **qml/**: Компоненты пользовательского интерфейса на QML
- **QmlModels/**: Модели данных для интеграции Qt/QML:
  - **CourseListModel**: Модель списка курсов
  - **CourseWorksListModel**: Модель списка учебных работ
  - **WordsSimilarityModel**: Модель для отображения схожести слов
  - **ProxyModel**: Прокси-модель для фильтрации и сортировки данных

## 🛠️ Зависимости

Проект требует следующие зависимости:

### Обязательные зависимости
- **CMake 3.20+** - Система сборки
- **C++23** - Современный стандарт C++
- **Qt 6** - Фреймворк GUI (Core, Quick)
- **LibTorch 2.7.1** - Библиотека PyTorch C++ для ML
- **Boost** - Библиотеки C++ (JSON, headers)
- **OpenSSL** - Безопасное сетевое взаимодействие
- **MyStem 3.1** - Лемматизатор для русского языка
- **pugixml 1.15** - Легковесная библиотека XML для обработки документов
- **minizip-ng 4.0.10** - Библиотека для работы с ZIP-архивами
- **Keychain 1.3.1** - Кросс-платформенный менеджмент учетных данных

### Зависимости для конкретных платформ
- **Linux**: Стандартные инструменты разработки (g++, make и т.д.)
- **Windows**: Компилятор MSVC или MinGW
- **macOS**: Инструменты командной строки Xcode

## 🚀 Инструкции по установке и сборке

### Предварительные требования

#### Linux (Ubuntu/Debian)
```bash
# Установите базовые инструменты сборки
sudo apt update
sudo apt install -y build-essential cmake git

# Установите Qt 6
sudo apt install -y qt6-base-dev qt6-declarative-dev

# Установите другие зависимости
sudo apt install -y libssl-dev libboost-all-dev
```

#### macOS
```bash
# Установите инструменты командной строки Xcode
xcode-select --install

# Установите зависимости через Homebrew
brew install cmake git qt@6 boost openssl
```

#### Windows
- Установите Visual Studio 2022 с инструментами разработки на C++
- Установите CMake (добавьте в PATH)
- Установите Qt 6 (убедитесь, что бинарные файлы Qt находятся в PATH)

### Сборка проекта

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/your-repo/AntiCopyRight.git
cd AntiCopyRight
```

2. **Создайте директорию сборки:**
```bash
mkdir build
cd build
```

3. **Настройте с помощью CMake:**
```bash
cmake .. -DCMAKE_BUILD_TYPE=Release
```

4. **Соберите проект:**
```bash
cmake --build . --config Release
```

5. **(Опционально) Установите:**
```bash
cmake --install .
```

### Опции сборки

Вы можете настроить сборку с помощью этих опций CMake:

- `-DBUILD_TESTS=ON/OFF` - Собрать модульные тесты библиотеки (по умолчанию: OFF)
- `-DBUILD_WITH_QT6=ON/OFF` - Использовать Qt 6 (по умолчанию: ON)

## 🔬 Технические детали

### Конвейер анализа текста
1. **Загрузка документов**: Поддержка различных форматов документов (DOCX)
2. **Извлечение текста**: Преобразование документов в сырой текст с использованием pugixml и minizip-ng
3. **Предобработка**: Удаление стоп-слов, нормализация текста
4. **Лемматизация**: Нормализация слов с помощью MyStem 3.1
5. **Векторизация**: Преобразование текста в числовые векторы с помощью Doc2Vec (LibTorch 2.7.1)
6. **Сравнение схожести**: Вычисление показателей схожести между документами

### Сетевая интеграция
- Управление аутентификацией через сетевые сессии
- Безопасное взаимодействие с использованием OpenSSL

### Машинное обучение
- Модель Doc2Vec для встраивания документов на базе LibTorch 2.7.1
- Алгоритмы обнаружения схожести на основе косинусного расстояния
- Настраиваемые пороги схожести
- Поддержка обучения и дообучения моделей
