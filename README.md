# AntiCopyRight - Система обнаружения плагиата


Полноценная система обнаружения плагиата для академических и профессиональных документов.

## 📋 О проекте

AntiCopyRight - это сложная система обнаружения плагиата, использующая передовые методы анализа текста, машинного обучения и обработки документов для выявления потенциального плагиата в академических работах, исследовательских статьях и других документах.

### Основные возможности:
- **Анализ документов**: Разбор и анализ различных форматов документов
- **Обработка текста**: Продвинутая нормализация и лемматизация текста
- **Машинное обучение**: Обнаружение схожести на основе Doc2Vec
- **Сетевая интеграция**: Облачная обработка документов
- **GUI на Qt**: Современный, удобный интерфейс
- **Поддержка нескольких языков**: В основном ориентировано на обработку русского языка

## 🔧 Обзор модулей

### Основная библиотека (`lib/`)
- **BoostNetwork**: Сетевое взаимодействие и аутентификация
- **Config**: Парсинг и управление конфигурационными файлами
- **DocumentManager**: Чтение и обработка документов
- **Network**: HTTP-запросы, управление токенами и интеграция с API
- **TextAnalyzer**: Конвейер обработки текста с лемматизацией и ML-моделями
- **Util**: Вспомогательные функции

### Приложение (`src/`)
- **main.cpp**: Точка входа в приложение с инициализацией Qt
- **qml/**: Компоненты пользовательского интерфейса на QML
- **QmlModels/**: Модели данных для интеграции Qt/QML

## 🚀 Инструкции по установке и сборке

### Предварительные требования

#### Linux (Ubuntu/Debian)
```bash
# Установите базовые инструменты сборки
sudo apt update
sudo apt install -y build-essential cmake git

# Установите Qt 6
sudo apt install -y qt6-base-dev qt6-declarative-dev qt6-networkauth-dev

# Установите другие зависимости
sudo apt install -y libssl-dev libboost-all-dev
```

#### macOS
```bash
# Установите инструменты командной строки Xcode
xcode-select --install

# Установите зависимости через Homebrew
brew install cmake git qt@6 boost openssl
```

#### Windows
- Установите Visual Studio 2022 с инструментами разработки на C++
- Установите CMake (добавьте в PATH)
- Установите Qt 6 (убедитесь, что бинарные файлы Qt находятся в PATH)

### Сборка проекта

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/your-repo/AntiCopyRight.git
cd AntiCopyRight
```

2. **Создайте директорию сборки:**
```bash
mkdir build
cd build
```

3. **Настройте с помощью CMake:**
```bash
cmake .. -DCMAKE_BUILD_TYPE=Release
```

4. **Соберите проект:**
```bash
cmake --build . --config Release
```

5. **(Опционально) Установите:**
```bash
cmake --install .
```

### Опции сборки

Вы можете настроить сборку с помощью этих опций CMake:

- `-DBUILD_TESTS=ON/OFF` - Собрать модульные тесты (по умолчанию: OFF)
- `-DBUILD_WITH_QT6=ON/OFF` - Использовать Qt 6 (по умолчанию: ON)
- `-DBUILD_WITH_QT5=ON/OFF` - Использовать Qt 5 (по умолчанию: OFF)

После сборки вы можете запустить приложение:

```bash

```

Приложение предоставляет графический интерфейс для:

## 🔬 Технические детали

### Конвейер анализа текста
1. **Загрузка документов**: Поддержка различных форматов документов
2. **Извлечение текста**: Преобразование документов в сырой текст
3. **Лемматизация**: Нормализация слов с помощью MyStem
4. **Векторизация**: Преобразование текста в числовые векторы с помощью Doc2Vec
5. **Сравнение схожести**: Вычисление показателей схожести между документами

### Сетевая интеграция
- Облачная обработка документов
- Управление аутентификацией
- Безопасное API-взаимодействие
- Аутентификация на основе токенов

### Машинное обучение
- Модель Doc2Vec для встраивания документов
- Алгоритмы обнаружения схожести
- Настраиваемые пороги схожести
